# 🎬 Netflix Clone — Frontend

A Netflix-inspired streaming platform frontend built as a learning project to practice modern web development and responsive UI design.

## 🚀 Features

- 🎬 Netflix-inspired modern UI
- 📱 Fully responsive design
- 🏠 Hero/banner section
- 🎞️ Movie and TV show categories
- 🔍 Search interface
- ▶️ Movie/show cards
- 📺 Interactive navigation
- ⚡ Dynamic content rendering
- 🎨 Modern and clean user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- React.js
- Git & GitHub

## 📚 What I Learned

- Building responsive layouts
- Creating reusable UI components
- Working with APIs
- Managing frontend state
- Handling user interactions
- Designing modern web interfaces
- Using Git and GitHub for version control

## 🎯 Purpose

This project was created as part of my frontend development learning journey and is intended for educational purposes.

This is a frontend learning project inspired by the design and functionality of streaming platforms. It is not affiliated with or endorsed by Netflix.
